# Бот-помощник для Telegram-чата

Юморной, но молчаливый: по умолчанию молчит, вступает только по поводу. Главная цель — не засорять чат.

## Как он решает говорить

1. **Дешёвый фильтр без ИИ** (`src/filter.js`): обращение по имени / `@нику` / ответом на бота; иначе — случайный шанс (2–20% в зависимости от `/активность`), триггеры («скучно», «кто-нибудь»…), лимит самостоятельных реплик в час, пауза ≥3 мин, не говорит дважды подряд, молчит при серьёзных темах и ссорах.
2. **ИИ с правом промолчать**: уходят последние 18 сообщений, модель отвечает `SKIP`, `REACT:<эмодзи>` или репликой в 1–2 строки (`src/prompts.js`, `src/parse.js`).

## Команды

Работают и по-русски, и латиницей (`/roast`, `/quiet`…). Telegram не подсвечивает кириллические команды, но бот их понимает.

`/тихо [мин]` · `/активность 1-5` · `/прожарь @ник` (или ответом) · `/неподкалывай` (повтор — вернуть) · `/тон мягко|жёстко` · `/табу <тема>`, `/табу_список`, `/табу_сброс` · `/итоги` · `/оживи` · `/помощь`

## Защиты подколов
- Промпт запрещает внешность, семью, здоровье и т. п.; подкол только за слова и поступки.
- `/неподкалывай` и табу-темы попадают в промпт, а реплика с упоминанием защищённого человека отбрасывается кодом.
- Один человек — не чаще раза в `ROAST_COOLDOWN_HOURS` (по умолчанию 3 ч); самостоятельная реплика с упоминанием участника тоже считается.
- При ссоре / грусти / серьёзных ключевых словах самостоятельные реплики выключены.

## Запуск

1. Создай бота в @BotFather, затем `/setprivacy` → **Disable** (иначе бот не видит обычные сообщения в группе). Добавь бота в чат.
2. Ключ Gemini — **aistudio.google.com** (подписка Google AI Plus API не включает). Ключ Grok необязателен; условия бесплатного доступа xAI проверь сам.
3. Скопируй `.env.example` в `.env` / задай переменные в Railway: `BOT_TOKEN`, `GEMINI_API_KEY`, при желании `GROK_API_KEY`.
4. `npm install && npm start`. Тесты: `npm test`.

### Railway
Подключи репозиторий, задай переменные окружения. Состояние (настройки, история) лежит в `DATA_DIR/state.json`: чтобы оно переживало деплои, подключи **Volume** в `/data` и поставь `DATA_DIR=/data`. Запускай одну реплику (long polling).

## Заметки
- Имена моделей (`GEMINI_MODEL`, `GROK_MODEL`) меняются — проверь актуальные в консолях провайдеров.
- Любой участник может вызвать `/тихо` и `/активность`; ограничение до админов — тривиальная доработка в `src/commands.js`.
- История чата хранится локально в JSON (последние 400 сообщений на чат) и в ИИ уходит только после прохождения фильтра.
